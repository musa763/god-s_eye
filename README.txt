GOD'S EYE V2 - XAMPP INSTALLATION

1. Extract gods_eye into C:\xampp\htdocs\
2. Start Apache and MySQL in XAMPP.
3. Open http://localhost/phpmyadmin
4. Import database.sql.
5. Open http://localhost/gods_eye/

Default login:
Username: admin
Password: password

V2 FEATURES:
- Role-based access: ADMIN, OPERATOR, VIEWER
- Secure password hashing
- CSRF protection on write forms
- Incident create/edit/delete, search and status filtering
- Threat creation and status updates
- Alert creation and status updates
- Response team status updates
- Admin user management
- Audit logging
- Responsive dashboard

For real deployment, change the database credentials, default password, enable HTTPS, and add server hardening/backups.
